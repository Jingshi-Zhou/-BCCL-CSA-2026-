# 第一届跨语言文学文本情感分析一致性评测 (BCCL-CSA 2026)

## 任务简介

跨语言情感分析一致性（**Cross-lingual Sentiment Consistency**）指同一文本在不同语言表征下情感标注保持一致的能力，是衡量多语言模型语义对齐质量的核心指标。

- **背景挑战：** 中国古典文学通常“含蓄蕴藉”，借助意象、历史典故和复杂修辞传递情感，非直接使用情感词汇，增加跨语言情感对齐难度。
- **现有评测缺口：** 目前缺少针对古典文学跨语言情感一致性的专门评测体系。

为此，BCCL-CSA 2026专注评估大语言模型在古典文学语境下的跨语言情感理解与对齐能力。

## 数据集 CCL-SEL 概况

- 精选自先秦至近代12部经典著作，涵盖哲学、小说、戏曲等多种体裁
- 共计3000组中英句子对
- 提供情感极性（正面、中性、负面）与六维基本情绪概率分布标注

## 任务设置

### 1. 细粒度情感识别（Fine-grained Sentiment Recognition）

- 单独对中、英文本进行情感极性识别和情绪分布预测（情感三分类）
- 评估模型对古典文学文本情感的深入理解能力

### 2. 跨语言情感一致性评估（Cross-lingual Sentiment Consistency Evaluation）

- 测评中英文本的情感预测结果在极性标签和六种基本情绪分布上的一致性
- 重点考察跨语言语义对齐能力
