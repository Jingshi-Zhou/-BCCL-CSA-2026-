# 第一届跨语言文学文本情感分析一致性评测（BCCL-CSA 2026）

## 任务简介
跨语言情感分析一致性（**Cross-lingual Sentiment Consistency**）是指同一语义内容在不同语言表达下，模型给出的情感判断是否保持一致。这一能力是衡量多语言模型语义对齐质量与跨语言鲁棒性的关键指标。

- **背景挑战：** 中国古典文学常通过意象、典故、隐喻与语境传递情感，显性情感词较少，跨语言迁移与一致性判断难度高。  
- **评测缺口：** 当前公开评测中，针对“文学文本 + 中英平行语料 + 情感一致性”的专门基准仍较少。  

为此，BCCL-CSA 2026 聚焦古典文学语境下的大模型跨语言情感理解、迁移与一致性评估。

## 数据集 CCL-SEL 概况
- 数据来源：中文文学文本及其人工英文译文构成的平行语料  
- 覆盖作品：**11 部**经典著作（哲学、小说、戏曲等体裁）  
- 样本规模：**2607 组**中英句对  
- 标注信息：
  - 情感极性（Sentiment）：`Positive / Neutral / Negative`
  - 情绪分布（Emotion）：**7 维**概率向量（Anger, Disgust, Fear, Joy, Sadness, Surprise, Neutral）
- 数据划分（固定随机种子 42，分层抽样）：
  - 训练集：**1562**（60%）
  - 验证集：**263**（10%）
  - 测试集：**782**（30%）
- 发布策略：
  - 训练/验证集：公开标签
  - 测试集：公开文本，标签隐藏用于评测

## 任务设置

### 任务一：单语言情感分类（Monolingual Sentiment Classification）
在中文或英文单语输入条件下，预测该文本的：
1. 情感极性标签（3 分类）  
2. 情绪分布（7 维概率向量）  

目标是评估模型对文学文本细粒度情感的单语理解能力。

### 任务二：跨语言零样本迁移（Cross-lingual Zero-shot Transfer）
在固定划分上进行跨语言迁移评估：
- 中文训练/验证，英文测试  
- 英文训练/验证，中文测试  

重点考察模型跨语言迁移能力与语义对齐稳定性。

### 任务三：平行文本一致性评估（Parallel Consistency Evaluation）
对同一 `zh-en` 平行句对进行一致性建模，评估中英文侧预测在极性与情绪分布上的一致程度。  
重点衡量模型在双语场景中的情感对齐质量。

## 评价指标（以最终评测细则为准）
- **Sentiment：** Accuracy、Macro-F1 等分类指标  
- **Emotion：** 分布距离类指标（如 KL/JS/MSE 等）与一致性指标  
- **Consistency：** 面向平行句对的跨语一致性评分指标
